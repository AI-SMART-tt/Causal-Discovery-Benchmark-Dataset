# FT-LCD Benchmark Evaluation: Experimental Design and Evaluation Protocol

## 1. Objective

This benchmark evaluates structural recovery when the generating graph is known. It examines whether applying FT-LCD with evidence-adaptive prior weighting (EAPW) to the output of a specified causal discovery algorithm changes the recovery of graph adjacencies and identifiable edge orientations.

Structural accuracy and stability address different questions. Accuracy measures agreement with a known reference structure. Stability measures consistency across repeated observations or perturbations. A stable graph can still be inaccurate. Known-structure benchmarks therefore provide direct accuracy evaluation, whereas stability and knowledge consistency in the observational EV-charging application remain diagnostic evidence.

Reference graphs are used to generate observations and evaluate predictions. Reference edges, numerical conditional probability tables, and generating coefficients are excluded from model fitting and LLM knowledge elicitation.

## 2. Experimental Workflow

The evaluation follows seven steps:

1. Specify the reference networks, generating mechanisms, sample sizes, and random seeds.
2. Elicit one set of LLM knowledge statements per network using variable metadata alone, and freeze these statements before the corresponding fitting runs.
3. Generate repeated observation datasets, holding the generating mechanism fixed within each network.
4. Run Original PC and Original GES separately on the same datasets.
5. Estimate data-based support for candidate directions and combine it with the frozen LLM knowledge through EAPW.
6. Refine each original algorithm's output using the FT-LCD objective and graph search.
7. Evaluate eligible estimates against reference completed partially directed acyclic graphs (CPDAGs), and aggregate paired observations.

No prior or final graph is selected using its agreement with the reference graph. The refined protocol was developed through retrospective methodological diagnosis; it is not an independently preregistered confirmation study.

## 4. Data Generation and Repeated Sampling

### 4.1 Categorical observations

Categorical observations are generated by ancestral sampling in the reference DAG's topological order. Each variable is sampled from its CPT conditional on its sampled parent states:

\[
P(\mathbf X)=\prod_{j=1}^{d}P\bigl(X_j\mid\mathbf X_{Pa_G(j)}\bigr),
\]

where \(d\) is the number of variables and \(Pa_G(j)\) denotes the parents of variable \(j\) in reference DAG \(G\). All published categories are retained, including states absent from a particular realization. Integer labels identify categories without imposing an ordinal interpretation. No missingness or measurement error is introduced.

### 4.2 Continuous observations

Continuous observations follow a linear Gaussian SEM:

\[
X_j=\sum_{i\in Pa_G(j)}\beta_{ij}X_i+\epsilon_j,
\qquad \epsilon_j\overset{\mathrm{ind}}{\sim}\mathcal N(0,1).
\]

For each reference edge, the coefficient magnitude is drawn from \(\mathrm{Uniform}(0.35,1.15)\), with a negative sign assigned with probability 0.35. Absent edges have zero coefficients. Each network's coefficient matrix is fixed across sample sizes and repeated datasets; independent noise realizations generate the repetitions.

Continuous variables are standardized separately within each dataset using their column means and population standard deviations, with a standard-deviation floor of \(10^{-12}\). Continuous observations are not discretized for the primary comparison.

### 4.3 Sample sizes and repetitions

| Design component | Setting |
|---|---|
| Primary comparison | \(n=1{,}000\) |
| Categorical sample sizes | 250, 500, 1,000, 5,000, 10,000 |
| Gaussian sample sizes | 1,000, 5,000 |
| Observation realizations per network and sample size | 10 |
| Observation-generation base seed | 20261017 |
| Derived seeds | SHA-256 of the base seed, network identifier, task, and realization index |

Within each network and realization, the largest dataset is generated first; smaller datasets use its first \(n\) observations. Sample-size conditions are therefore nested and statistically dependent. Different realization indices use different observation seeds. The design contains 450 categorical and 220 Gaussian datasets.

The completed refined-method evaluation covers both algorithms on all 20 networks at \(n=1{,}000\), together with all five categorical sample sizes for GES. Complete refined-method coverage of the remaining algorithm–data-family–sample-size combinations is not assumed.

### 4.4 Supplementary nonlinear condition

A separate stress condition uses the eleven continuous reference structures, with three realizations per network at \(n=1{,}000\). For a node with \(k_j>0\) parents, define

\[
v_j=\sum_{i\in Pa_G(j)}\beta_{ij}X_i+\epsilon_j,
\qquad
X_j=\tanh\!\left(\frac{v_j}{1+0.2k_j}\right)+\xi_j,
\]

where \(\epsilon_j\sim\mathcal N(0,1)\) and \(\xi_j\sim\mathcal N(0,0.35^2)\) are independent innovations. Root nodes retain standard Gaussian noise. This condition is evaluated separately from the primary families and is outside the completed refined-method coverage stated above.

## 5. Paired Algorithm Comparisons

The primary comparisons are conducted separately:

- **Original PC versus FT-LCD EAPW initialized from PC.**
- **Original GES versus FT-LCD EAPW initialized from GES.**

Within each pair, methods use identical observations, variable ordering, preprocessing, and original algorithm output. PC and GES are not averaged into a single baseline.

| Method | Initial estimate | Subsequent procedure |
|---|---|---|
| Original PC | PC output | Retain the original estimate |
| FT-LCD EAPW (PC) | Consistent DAG extension of the PC output | Optimize the FT-LCD objective |
| Original GES | GES output | Retain the original estimate |
| FT-LCD EAPW (GES) | Consistent DAG extension of the GES output | Optimize the FT-LCD objective |

FT-LCD refinement can add, delete, or reverse edges, changing both skeleton and orientations. It is a second-stage DAG search initialized from PC or GES, rather than an orientation-only modification of PC or another execution of standard GES.

A supplementary data-only refinement control uses the same initialization and search operations but removes all knowledge terms. This diagnostic control distinguishes additional score-based search from LLM knowledge integration.

### 5.1 Original PC

| Parameter | Categorical data | Continuous data |
|---|---|---|
| Implementation | causal-learn PC | causal-learn PC |
| Conditional independence test | G-square | Fisher-Z |
| Significance level | 0.05 | 0.05 |
| Stable skeleton search | Enabled | Enabled |
| Collider rule | `uc_rule = 0` | `uc_rule = 0` |
| Conflict priority | `uc_priority = 2` | `uc_priority = 2` |
| Reference or LLM constraints | None | None |

### 5.2 Original GES

Original GES uses causal-learn's equivalence-class search with type-specific local scores. A score adapter supplies the same data-score definition used in FT-LCD refinement, with larger scores indicating better fit. Reachability and subset-checking adaptations accelerate the search without introducing knowledge or reference-edge constraints.

The parent-limit parameter supplied to GES is 4, and the BIC penalty multiplier is 1. The refinement-stage parent limit is defined separately in Section 8.

## 6. Type-Specific Data Scores

### 6.1 Categorical BIC

For variable \(j\), let \(r_j\) be its number of states, \(q_j\) the number of possible parent-state configurations, \(N_{uk}\) the count for parent configuration \(u\) and child state \(k\), and \(N_u=\sum_kN_{uk}\). The local score is

\[
s_j(Pa_j)=\sum_{u=1}^{q_j}\sum_{k=1}^{r_j}N_{uk}\log\frac{N_{uk}}{N_u}
-\frac12q_j(r_j-1)\log n.
\]

Zero-count likelihood terms contribute zero. The penalty uses the full declared state cardinalities. Category labels do not enter the score as numerical measurements.

### 6.2 Gaussian BIC

For continuous variables,

\[
s_j(Pa_j)=-\frac n2\log\left[\max\{\widehat\sigma^2_{j\mid Pa_j},0\}+10^{-10}\right]
-\frac{|Pa_j|}{2}\log n,
\]

where \(\widehat\sigma^2_{j\mid Pa_j}\) is the least-squares residual variance. Terms constant across candidate graphs are omitted. GES and FT-LCD refinement share these score definitions; PC uses conditional independence tests.

## 7. LLM Knowledge and EAPW

### 7.1 Knowledge elicitation

One knowledge set is elicited per network using DeepSeek `deepseek-flash`, with temperature 0, a maximum of 16,000 output tokens, JSON output, disabled thinking, and no streaming. The first complete, schema-valid response is retained. Up to three attempts are allowed for transport or schema failures; responses are not selected by structural recovery performance.

The prompt contains variable names, descriptions, and available state labels. It excludes observations, numerical CPTs, reference edges, generating coefficients, true causal orders, and evaluation outcomes. The same frozen response is reused across observation realizations, sample sizes, and PC/GES comparisons.

Knowledge statements distinguish:

- **Direct relations:** a proposed direct edge, with confidence from 1 to 5.
- **Ancestral relations:** a proposed directed path without requiring a direct edge.
- **Abstentions:** insufficient knowledge to specify a relation.
- **Partial order statements:** relative causal ranks, allowing ties and omitted variables.

Each direct nomination also has a semantic-certainty value \(\zeta_{ij}\in[0,1]\), elicited separately from relation confidence. Public network descriptions may be familiar from pretraining; excluding reference edges from the prompt does not establish the absence of prior model familiarity.

### 7.2 Direct-edge encoding

A direct nomination with confidence \(c_{ij}\) is encoded as

\[
p^{LLM}_{ij}=c_{ij}/5.
\]

Unmentioned pairs and abstentions receive the neutral value 0.5. An ancestral statement does not itself create a direct-edge prior. These values are scoring inputs, not empirically calibrated causal probabilities. Confidence scores of 1 or 2 map below 0.5 under this encoding.

### 7.3 Data-based support

Each observation dataset undergoes \(B=10\) bootstrap resamples, each containing \(n\) rows sampled with replacement. Each resample is fitted from an empty DAG using only the data score, with at most four parents per node.

For candidate direction \(i\rightarrow j\), define the nonnegative local-score gain in bootstrap sample \(b\):

\[
g^{(b)}_{ij}=\max\left\{0,\max_{Z\in\mathcal V^{(b)}_{ij}}
\left[s_j^{(b)}(Z\cup\{i\})-s_j^{(b)}(Z)\right]\right\}.
\]

Here, \(\mathcal V^{(b)}_{ij}\) contains conditioning sets evaluated through the search's visited local parent sets, including singleton-parent comparisons, with \(|Z\cup\{i\}|\leq4\). If no evaluated comparison supports a gain, the value is zero. This maximum over **visited conditioning sets** is a computational approximation, not exhaustive enumeration of all possible conditioning sets.

Average and normalize the gains:

\[
\overline g_{ij}=\frac1B\sum_{b=1}^{B}g^{(b)}_{ij},\qquad
\widetilde g_{ij}=\frac{\overline g_{ij}}{\max_{a\neq c}\overline g_{ac}+10^{-12}}.
\]

Let \(C^{(b)}\) be the CPDAG obtained from the data-only bootstrap DAG. Directional frequency is

\[
\nu_{ij}=\frac1B\sum_{b=1}^{B}\mathbb 1[i\rightarrow j\text{ is directed in }C^{(b)}].
\]

Arbitrary directions introduced by an equivalent DAG completion do not contribute to this frequency. The combined support is

\[
\rho_{ij}=\eta\widetilde g_{ij}+(1-\eta)\nu_{ij},\qquad\eta=0.5.
\]

Bootstrap seeds derive from base seed 20261020 and the network, condition, sample size, realization, and bootstrap index. PC and GES use the same support estimates for a given dataset.

### 7.4 Adaptive prior weights

EAPW computes

\[
\alpha_{ij}=\operatorname{sigmoid}\left[w_1(1-\rho_{ij})+w_2\zeta_{ij}+b_0\right],
\qquad w_1=2,\quad w_2=1.5,\quad b_0=-0.2,
\]

where \(\operatorname{sigmoid}(x)=1/(1+e^{-x})\). The effective prior is

\[
p^{eff}_{ij}=\alpha_{ij}p^{LLM}_{ij}+(1-\alpha_{ij})\times0.5.
\]

Higher data support reduces the LLM weight under this rule; greater semantic certainty increases it. Unmentioned pairs remain neutral regardless of their weight. Effective probabilities are clipped to \([10^{-9},1-10^{-9}]\) before computing log-odds.

## 8. FT-LCD Objective and Graph Search

### 8.1 Optimization objective

For candidate DAG \(H\), maximize

\[
\begin{aligned}
S(H)={}&\sum_j s_j(Pa_H(j))
+\lambda_e(n)\sum_{i\rightarrow j\in H}\log\frac{p^{eff}_{ij}}{1-p^{eff}_{ij}}\\
&+\lambda_a(n)\sum_{(a,d)\in\mathcal A}\frac{c_{ad}}5\mathbb 1[a\leadsto_H d]\\
&-\lambda_o(n)\sum_{(a,b,w)\in\mathcal O}w\mathbb 1[b\leadsto_H a].
\end{aligned}
\]

Here, \(\mathcal A\) contains ancestral nominations, \(\mathcal O\) contains ordered pairs, and \(a\leadsto_H d\) denotes a directed path in \(H\). Repeated ancestral nominations for a pair retain the largest confidence. An ancestral reward requires reachability, rather than a direct edge.

If the LLM ranks \(a\) before \(b\), the order term penalizes a path from \(b\) back to \(a\). Incomparable nodes incur no penalty; tied ranks generate no ordered pair. For a strict rank gap \(\Delta r\),

\[
w=\operatorname{round}\{\min(0.18+0.04\Delta r,0.35),3\}.
\]

The objective depends on graph reachability, not an arbitrarily chosen topological ordering. Graph-independent constants are omitted.

### 8.2 Sample-size scaling

All three knowledge coefficients use the same scaling rule:

\[
t(n)=\min(1,n_{ref}/n),\qquad n_{ref}=2{,}000,
\]

\[
\lambda_e(n)=10t(n),\qquad
\lambda_a(n)=\tfrac12\log(2{,}000)t(n),\qquad
\lambda_o(n)=0.4\lambda_a(n).
\]

The edge-specific EAPW weight controls individual prior shrinkage, whereas these coefficients control the overall knowledge contribution. Parameter rules are shared across networks and sample sizes.

### 8.3 Initialization and search

A deterministic Dor–Tarsi consistent extension converts an eligible original output into a DAG while preserving its skeleton and existing directions. The extension is selected without reference-graph information.

FT-LCD searches through legal edge additions, deletions, and reversals. All distinct-node pairs are candidates. Acyclicity is enforced, and the refinement parent limit is

\[
K_{refine}=\max\left(4,\max_j|Pa_{H_0}(j)|\right),
\]

where \(H_0\) is the initial DAG. This avoids deleting original edges merely to impose a smaller initialization limit. The same limit is used within each paired refinement task.

Accepted operations increase the complete objective, including reachability terms. Search stops when the implemented phases identify no legal positive-gain operation. A safeguard limits accepted operations to 10,000; reaching that limit requires a separate convergence check. This local search does not guarantee a global optimum.

If an original output has no consistent extension, it is retained unchanged and refinement is marked unavailable. No reference-based repair or performance-based fallback is applied. Paired comparisons use common evaluable tasks and report coverage.

## 9. Structural Recovery Metrics

### 9.1 Evaluation target

The reference DAG is converted to a CPDAG representing its observational Markov equivalence class. Refined DAGs are also converted to CPDAGs. Eligible Original outputs are evaluated through canonical CPDAGs obtained from consistent extensions; their original endpoint information is retained separately.

Undirected CPDAG edges represent directions not uniquely determined within the equivalence class. Directed edges are compelled: their orientations are shared by every DAG in that class. Compelled-edge metrics therefore evaluate these directions, rather than all arrows of an arbitrarily completed DAG.

### 9.2 Skeleton recall and F1

Let \(E\) and \(\widehat E\) be reference and estimated skeleton edge sets, represented as unordered node pairs:

\[
TP_s=|\widehat E\cap E|,\quad FP_s=|\widehat E\setminus E|,\quad FN_s=|E\setminus\widehat E|.
\]

\[
\mathrm{Skeleton\ R}=\frac{TP_s}{TP_s+FN_s},\qquad
\mathrm{Skeleton\ F1}=\frac{2TP_s}{2TP_s+FP_s+FN_s}.
\]

Recall measures the proportion of true connections recovered. F1 accounts for missed and extra connections. Skeleton precision is omitted from the presentation.

### 9.3 Compelled precision, recall, and F1

Let \(D\) and \(\widehat D\) be directed-edge sets of the reference and estimated CPDAGs. A true positive requires the correct pair and orientation:

\[
TP_c=|\widehat D\cap D|,\quad FP_c=|\widehat D\setminus D|,\quad FN_c=|D\setminus\widehat D|.
\]

\[
\mathrm{Compelled\ P}=\frac{TP_c}{TP_c+FP_c},\qquad
\mathrm{Compelled\ R}=\frac{TP_c}{TP_c+FN_c},\qquad
\mathrm{Compelled\ F1}=\frac{2TP_c}{2TP_c+FP_c+FN_c}.
\]

An undirected prediction does not recover a compelled reference direction; a reversed prediction is also incorrect. Each metric occupies a separate column. Larger values indicate better recovery.

### 9.4 SHD-CP and normalized SHD-CP

For each unordered pair, define its CPDAG state as absent, undirected, directed in one direction, or directed in the reverse direction. Then

\[
\operatorname{SHD\!\text{-}CP}=\sum_{i<j}\mathbb 1[\widehat C_{ij}\neq C_{ij}],
\]

where \(C_{ij}\) denotes the complete pair state. A reversal, addition, deletion, or undirected-to-directed change costs one for that pair.

\[
\operatorname{nSHD\!\text{-}CP}=\frac{\operatorname{SHD\!\text{-}CP}}{\max(|E|,1)}.
\]

Smaller values indicate closer agreement. Normalized SHD can exceed 1; it is not a bounded error probability. This convention differs from implementations counting a reversal as two operations.

### 9.5 Undefined metrics and unavailable outputs

| Condition | Treatment |
|---|---|
| Reference compelled edges exist, but none are predicted | Compelled P, R, and F1 are set to 0 |
| Reference CPDAG has no compelled edge | All three compelled metrics are NA and excluded from their averages |
| No consistent extension is available | CPDAG-based paired metrics are unavailable; status and coverage are retained |
| Original mean is zero in a percentage-change calculation | Percentage change is NA; an absolute difference can be reported |

Categorical Sachs and Gaussian Asia-M have no reference compelled edges. They remain eligible for applicable skeleton and distance metrics. Effective network counts can differ across metrics.

## 10. Aggregation, Uncertainty, and Relative Change

### 10.1 Network-specific summaries

Metrics are calculated separately for every observation realization, then summarized by network, algorithm, sample size, and method using means, sample standard deviations, and valid realization counts. Mean F1 is the mean of individual F1 values, not F1 recalculated from mean precision and recall.

### 10.2 Overall summaries

Summaries remain separate by data family, algorithm, sample size, and method. For metric \(m\), first calculate an equally weighted network average within realization \(r\):

\[
M_r=\frac1{|\mathcal K_r|}\sum_{k\in\mathcal K_r}m_{kr},
\]

where \(\mathcal K_r\) is the common eligible network set for the comparison and metric. Then calculate

\[
\overline M=\frac1R\sum_{r=1}^{R}M_r,\qquad
SD(M)=\sqrt{\frac1{R-1}\sum_{r=1}^{R}(M_r-\overline M)^2},\qquad R=10.
\]

This macro-averaging gives each eligible network equal weight. Coverage is reported when eligibility varies.

### 10.3 Relative change from Original

For metrics where larger values are preferred,

\[
\Delta_{\%}=100\frac{\overline M_{FT}-\overline M_{Original}}{\overline M_{Original}}.
\]

For SHD-CP and nSHD-CP, where smaller values are preferred,

\[
\Delta_{\%}=100\frac{\overline M_{Original}-\overline M_{FT}}{\overline M_{Original}}.
\]

Positive values indicate change in the preferred direction. Percentages are calculated from paired aggregate means, not by averaging network-specific percentage changes.

### 10.4 Interpretation of uncertainty

Error bars or bands show the sample standard deviation across observation realizations unless stated otherwise. They are not confidence intervals or significance tests. Repeated fitting of identical data does not create independent observations. The ten support-estimation bootstraps are distinct from the ten observation realizations used for performance summaries.

Because sample sizes are nested and some reference networks are related, individual sample-size conditions or related graphs should not automatically be treated as independent units. No confirmatory significance claim follows from descriptive summaries alone.

## 11. Reporting Structure and Scope

| Component | Comparison | Purpose |
|---|---|---|
| Primary comparison | Original versus FT-LCD EAPW at \(n=1{,}000\), separately for PC and GES | Compare recovery at a common observation budget |
| Data-family comparison | Separate categorical and Gaussian conditions | Retain differences in generation and scoring |
| Sample-size sensitivity | Vary \(n\), fixing the generating mechanism and LLM knowledge | Examine dependence on observation count |
| Network-wise comparison | Retain each network at \(n=1{,}000\) | Describe heterogeneity beyond aggregate means |
| Data-only refinement control | Remove knowledge, retaining refinement search | Distinguish extra search from knowledge integration |

Tables use separate columns for Skeleton R, Skeleton F1, Compelled P, Compelled R, Compelled F1, SHD-CP, and nSHD-CP. Relative changes follow the metric-specific convention above.

The design evaluates recovery under the specified, fully observed mechanisms. It does not establish correctness of the EV-charging graph, identify every DAG direction from observational data, or establish performance under latent confounding, missingness, or nonstationarity. The visited-conditioning-set approximation and ten support-estimation bootstraps remain explicit features of the implemented EAPW procedure.
